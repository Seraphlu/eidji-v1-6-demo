# 《额吉》竖切 Demo · v1.6 可玩性修订

这是一个依据《额吉》v1.5（终检修订）策划案制作的浏览器竖切 Demo。当前版本优先验证完整玩法链路与叙事节奏，**正式美术资源尚未接入**，场景、角色与小游戏均使用明确标注的灰盒占位。

## 运行

最简单的方式：

1. 双击 `启动Demo.bat`。
2. 或直接双击 `index.html`。

如果浏览器对 `file://` 存档有限制，可在本目录运行：

```powershell
python -m http.server 8765
```

然后打开 <http://localhost:8765>。

无需安装 Node.js 或任何前端依赖。

## 当前可玩内容

- 主菜单“立即试玩第一章”：跳过序章，几秒内直接进入可操作探索。
- 序章：5 道“不可能选项”问卷，选项随机排序，答案静默记录。
- 第一章：可在慈云庵场景中走动，`Shift` 加速，每天有 48 秒暮色倒计时和 2 次主要行动；可在路上拾取干柴、炭笔和野菜，超时会冻伤并直接进入黄昏。
- 行动交互：包含领粥 QTE、野菜辨认、摸鱼、剥树皮、擦锅、照顾小囡、凝神祈祷、休息。
- 操作反馈：拾取、成功、失败、临近天黑与点击地点均有轻量音效，可在设置中关闭。
- v1.5 扩展：12 个地图地点、技能熟练度、灶台配方、状态词条、炊烟/人气、动态天气情报与每日风声。
- 黄昏分食：把稀粥、野菜、榆皮粉、鱼虾、红薯拖拽或点选分给自己、小囡或石头。
- 四维生存属性：饱食、体温、健康、心力；低心力与低体温会改变画面氛围。
- 道德事件：D5、D9、D14、D17 的关键选择；不显示善意值。
- D25：风雪终局，操作被接管，只保留【把碗给她】。
- 间章：黑屏声音蒙太奇占位。
- 第二章：28 张床围成圆圈的“额吉体验”小游戏，需求会升级为哭声并唤醒邻床。
- 五人群像：慧明师父、石头、小囡、陈婶、刺头各有牵绊记忆与 v1.5 关键抉择回扣。
- 白原梦境：祈祷或关键剧情夜进入递进式梦境，间章后在白原尽头与娜仁相遇。
- 终章：逐题回扣序章答案、第六问、我愿意 / 我再想想、光的传承演出与五张脸回扣。
- 本地存档、温柔模式、档案室解锁、隐藏成就。
- 桌面与 390px 手机视口自适应，鼠标、键盘与触屏点击均可完成主要流程。

## 操作

| 场景 | 操作 |
| --- | --- |
| 问卷 / 对话 | 鼠标点击、触屏点击 |
| 第一章 | `A/D` 或方向键移动，`Shift` 快跑，靠近地点按 `E` 互动；每天 48 秒暮色时间、2 次行动，可点“回庵”提前结束；黄昏拖拽分食 |
| 地图 / 手札 | `M` / `J` |
| 额吉体验 | `WASD` / 方向键移动，靠近亮起需求的小床；也可直接点击小床 |
| 暂停 | `Esc` |
| D25 终局 | 点击唯一交互【把碗给她】，或按 `E` |

## 美术资源替换

美术入口集中位于 `js/data.js` 的 `ART_MANIFEST`。把图片放到 `assets/`，再填写对应路径即可；Canvas 会优先绘制正式背景，加载失败时才回退到灰盒占位。

```js
const ART_MANIFEST = {
  chapter1Background: "assets/chapter1-background.png",
  chapter1Winter: "assets/chapter1-winter.png",
  finalSnow: "assets/final-snow.png",
  grasslandBackground: "assets/grassland-background.png",
  yurtNight: "assets/yurt-night.png",
  xiaowei: "assets/xiaowei.png",
  xiaonan: "assets/xiaonan.png",
  stone: "assets/stone.png",
  naren: "assets/naren.png",
  clothTiger: "assets/cloth-tiger.png"
};
```

目前实际接入的是两张第一章背景：`chapter1Background` 与 `chapter1Winter`。其余清单键位已预留，后续可以在正式引擎或本 Demo 中继续接入。

详细规范见 `assets/README.md`。

## 调试入口

这些参数只用于验收和演示，不会出现在正常流程里：

- `?demo=chapter&day=9`：直接进入第一章第 9 天。
- `?demo=chapter&day=1&phase=action`：跳过当天事件，直达行动选择。
- `?demo=chapter&day=1&phase=dusk`：直达黄昏分食。
- `?demo=final&phase=final`：直达 D25 终局。
- `?demo=grassland`：直达额吉体验开场。
- `?demo=grassland&autostart=1&fast=1`：自动开始并压缩到 12 秒。
- `?demo=dream&count=3`：直达第三次白原梦境。
- `?demo=ending`：直达终章回扣。
- `fast=1` 会压缩间章和额吉体验的时长，便于测试。

## 已知范围

- 这是玩法竖切，不是完整 60–90 分钟成品。
- 第一章为压缩版：每天两次主要行动，25 天全流程可在较短时间内体验完。
- 已有单屏场景行走与地点交互，但完整横版卷轴、正式环境音与逐帧过场尚未实现。
- 美术、UI 纹理、角色立绘与音频均为占位，需后续替换。
- 历史档案内容取自策划案所载公开史料摘要；参赛前需补齐授权、影像与准确出处。

## 剧情文字编辑器

双击 `启动编辑器.bat`，浏览器会打开剧情文字工坊，并启用本地保存与一键发布：

<http://localhost:8765/editor.html>

编辑器可修改序章、25 天事件、人物、地图、梦境、档案、食物和行动等文本，并支持：

- 全文搜索
- 批量查找替换
- 自动保存浏览器草稿
- 内容缺失检查
- 导出 JSON 备份
- 保存为可直接替换的 `js/data.js`
- 保存到游戏后自动备份旧文件
- 一键发布到 GitHub Pages 线上版本

使用 `Ctrl + S` 也可以快速保存。保存时建议先保留一份 `js/data.js` 备份。
